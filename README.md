## 📖 Overview

This repository accompanies our published research paper entitled **"AugCXR Dataset: Augmented Chest X-Ray Datasets for Robust Pneumonia Diagnosis Using Deep Learning"**, published in *Engineering, Technology & Applied Science Research (ETASR)*.

The study introduces **AugCXR**, an augmented chest X-ray dataset designed to address class imbalance and improve pneumonia diagnosis using deep learning. Multiple convolutional neural network architectures were evaluated to demonstrate the effectiveness of the proposed dataset in enhancing diagnostic performance.
